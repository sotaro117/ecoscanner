# Proyecto Final
El transport de mercaderies, especialment en el sector de l'alimentació, és una de les
principals fonts d'emissions de gasos d'efecte hivernacle. Com a futurs desenvolupadors
(DAM), el vostre repte és crear el Producte Mínim Viable (MVP) d'una app mòbil a
Android (amb Jetpack Compose) que fomenti el consum de proximitat (Km 0). L'aplicació
permetrà a l'usuari escanejar un producte, n'identificarà el país o lloc d'origen i,
calculant la distància fins a la posició actual de l'usuari, li dirà quant està contaminant
(emissions de CO2) per culpa del transport abans de comprar-lo. Per portar un registre
segur de les emissions estalviades, l'app requerirà un inici de sessió (Login).
